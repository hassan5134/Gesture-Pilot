代码
可用的 gp 工具

页面

gp.url / gp.title
当前页面地址与标题
gp.task
当前任务名
gp.$(sel) / gp.$$(sel)
查单个 / 查全部，等价于 querySelector
gp.waitFor(sel, ms)
等元素出现，超时返回 null
gp.sleep(ms)
等待
gp.log(...)
写进执行日志（开了 debug 才记）

说明

console.log
会被捕获进执行日志，同时照常打到页面控制台
返回值
用 return 交回来，会显示在日志里，方便确认这段代码到底爬到了什么
执行上下文
页面主世界，能访问页面自己的变量（jQuery、React 实例等）

默认先用轻量注入执行；如果站点 CSP 禁止 eval，会自动改用调试接口重试 （页面顶部会出现「正在调试此浏览器」提示条）。
